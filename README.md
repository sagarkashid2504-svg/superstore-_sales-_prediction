# Item Outlet Sales Prediction

## 📌 Project Description

This project uses Machine Learning to predict **Item Outlet Sales** based on product and outlet-related information. The model analyzes factors such as item weight, visibility, MRP, outlet size, location, and outlet type to estimate the expected sales of a product.

## 🎯 Objective

The main objective of this project is to build a machine learning model that can predict product sales at different outlets and help in better business and inventory planning.

## 📊 Dataset

The dataset contains **8,523 records** and **12 columns**.

### Features

* `Item_Identifier` – Unique identifier of the product
* `Item_Weight` – Weight of the product
* `Item_Fat_Content` – Fat content of the product
* `Item_Visibility` – Visibility of the product in the outlet
* `Item_Type` – Type/category of the product
* `Item_MRP` – Maximum Retail Price of the product
* `Outlet_Identifier` – Unique identifier of the outlet
* `Outlet_Establishment_Year` – Year the outlet was established
* `Outlet_Size` – Size of the outlet
* `Outlet_Location_Type` – Location tier of the outlet
* `Outlet_Type` – Type of outlet

### Target Variable

`Item_Outlet_Sales` – Sales of the product in a particular outlet.
